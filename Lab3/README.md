# Лабораторная 3 — RunBaza

Навигация, формы и валидация в существующем Flutter-проекте **Lab2/run_baza**.
Платформа демонстрации — iOS. Исходная Л2 сохранена в `lab/2-runbaza-ui`;
работа Л3 ведётся в `lab/3-navigation-forms` и включается в `main` через PR.

## Запуск

```sh
cd Lab2/run_baza
flutter pub get --enforce-lockfile
open -a Simulator
flutter devices
flutter run -d <simulator-id>
```

Для Xcode откройте `Lab2/run_baza/ios/Runner.xcworkspace`, выберите Runner и
симулятор iPhone. Код UI находится в `Lab2/run_baza/lib`.

Вход принимает любой синтаксически корректный e-mail и пароль от 6 символов,
например `runner@example.com` / `runbaza26`. Это локальная проверка формы,
без аккаунта, сервера и сохранения пароля.

## Реализовано

- `go_router`, `MaterialApp.router`, маршруты по строковому ID.
- Пять независимых вкладок `StatefulShellRoute.indexedStack` и `NavigationBar`.
- Поиск по названию, городу и дистанциям; фильтр страны.
- Формы входа, регистрации, участия в забеге, поездки водителя, запроса пассажира и профиля.
- `Form`, `GlobalKey<FormState>`, validators, controllers с `dispose`, фильтры ввода.
- `SnackBar` после проверки; `AlertDialog<bool>` перед выходом.
- Обработка неизвестных путей, ID и дистанций.
- Светлая и тёмная темы, иллюстрации городов и анимации из Л2.

Данные фиксированы. Отправка формы не создаёт запись, не бронирует место и
не отправляет запрос в сеть. Персистентность и реальная авторизация — следующий этап.

## Регистрация (добавление к Л3)

На экране входа нажмите **«Создать профиль»**. Маршрут `/register` содержит
имя (2–60 символов), e-mail, пароль (не менее 8 символов без учёта крайних
пробелов) и точное повторение пароля. Есть отдельные кнопки показа паролей.
Пустые поля, неверный e-mail и несовпадающие пароли блокируют переход.
После проверки открывается главная; имя и e-mail видны во вкладке «Профиль».
Кнопка «Уже есть профиль? Войти» возвращает к введённым данным входа.

Это локальный сценарий формы: серверный аккаунт не создаётся. Имя и e-mail
живут только в памяти текущего запуска, пароль не сохраняется и не отправляется.
Реальная проверка существования e-mail и авторизация потребуют backend.

На защите: отправить пустую форму → заполнить поля → показать несовпадение
паролей → исправить → открыть главную и профиль. Новые файлы:
`lib/screens/register_screen.dart`, `lib/data/runner_identity.dart`,
`test/registration_test.dart`, `integration_test/registration_test.dart`.
Снимки дополнения: `evidence/ios/20-registration.png`,
`21-registration-errors.png`, `22-registered-profile.png`.
Отчёт и PDF-гайд от 11.10 описывают базовую Л3; это дополнение от 12.10.
